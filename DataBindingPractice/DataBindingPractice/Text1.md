* **Яка модель даних використовується:**
  Використовується модель `Product` (Товар), яка містить три властивості: `Name` (рядок), `Price` (число), `Quantity` (ціле число). Клас реалізує інтерфейс `INotifyPropertyChanged`.

* **Які властивості моделі зв’язані з елементами інтерфейсу:**
  Властивість `Name` зв'язана з властивістю `Text` поля `txtName`. `Price` зв'язана з `txtPrice.Text`, а `Quantity` — з `txtQuantity.Text`.

* **Який механізм Data Binding використано:**
  Використано двостороннє зв’язування (Two-Way Binding) через колекцію `DataBindings` у Windows Forms. Режим оновлення встановлено як `DataSourceUpdateMode.OnPropertyChanged`.

* **Як відбувається оновлення даних та інтерфейсу:**
  Коли користувач вводить текст, Data Binding автоматично конвертує значення і записує його в модель. Коли властивість моделі змінюється з коду (наприклад, застосування знижки), модель викликає подію `PropertyChanged`, інтерфейс перехоплює її та автоматично оновлює текст у `TextBox`.

* **Чим Data Binding відрізняється від ручного присвоєння значень елементам GUI:**
  При ручному присвоєнні (наприклад, `txtName.Text = currentProduct.Name`) потрібно писати окремий код для завантаження даних у форму і окремий код для збереження даних назад в об'єкт при кожному натисканні кнопки "Зберегти". Data Binding створює постійний автоматичний міст між інтерфейсом та моделлю: дані синхронізуються самостійно без додаткового коду для кожної дії.
