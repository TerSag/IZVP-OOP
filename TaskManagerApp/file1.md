# Відповіді на контрольні запитання (Практична робота №15)

1. **Що означає кросплатформність програмного забезпечення?**
   **Відповідь:** Кросплатформність — це здатність програмного забезпечення працювати на різних операційних системах та апаратних архітектурах (наприклад, Windows, Linux, macOS) без необхідності переписування або з мінімальними змінами вихідного коду.

2. **Для чого використовується Avalonia UI?**
   **Відповідь:** Avalonia UI — це сучасний кросплатформний фреймворк для створення графічних інтерфейсів (GUI) на платформі .NET (C#), який дозволяє розробляти єдиний інтерфейс для Windows, Linux, macOS, iOS, Android та WebAssembly.

3. **Чим Avalonia UI відрізняється від Windows Forms?**
   **Відповідь:** Windows Forms є застарілим і платформно-залежним фреймворком, що працює переважно на Windows та базується на обгортках навколо Win32 API. Натомість Avalonia UI є повністю кросплатформним, використовує потужну систему стилів на основі CSS/XAML, підтримує сучасну прив'язку даних (Data Binding) та рендериться незалежно від платформи.

4. **Як у C# обробляються події елементів графічного інтерфейсу?**
   **Відповідь:** Події обробляються за допомогою делегатів (наприклад, `EventHandler`, `RoutedEventHandler`), шляхом підписки на події елемента керування у код-бехайнді (наприклад, `Button.Click += MethodName`) або декларативно у розмітці XAML (наприклад, `Click="MethodName"`).

5. **Яким чином можна відокремити логіку застосунку від графічного інтерфейсу?**
   **Відповідь:** Логіку відокремлюють за допомогою архітектурних патернів (MVVM — Model-View-ViewModel, MVC, MVP), винесення бізнес-логіки у незалежні сервіси чи класи моделей, а також використання механізмів прив'язки даних (Data Binding) і команд (`ICommand`) замість прямого звернення з обробників подій UI.
