# Відповіді на контрольні запитання до практичної роботи

### 1. Що таке REST API та яку роль він виконує у вашій програмі?
**Відповідь:** REST API (Representational State Transfer Application Programming Interface) — це архітектурний стиль взаємодії між програмами за допомогою протоколу HTTP. У нашій програмі він виконує роль віддаленого сервера-джерела даних, до якого застосунок надсилає запит для отримання масиву публікацій у форматі JSON.

### 2. Для чого використовується HTTP-метод GET?
**Відповідь:** HTTP-метод `GET` використовується для запиту та отримання даних з певного ресурсу без зміни їхнього стану на сервері (операція читання). У програмі він застосовується для завантаження списку постів із `https://jsonplaceholder.typicode.com/posts`.

### 3. Як отримані JSON-дані перетворюються на інформацію в GUI?
**Відповідь:** Отримана від сервера текстова JSON-відповідь за допомогою десеріалізатора (`System.Text.Json`) перетворюється у колекцію об'єктів моделі `List<Post>`. Після цього колекція прив'язується до елемента інтерфейсу (`ListBox.DataSource`), а деталі обраного об'єкта відображаються у відповідних текстових елементах форми (`Label` / `TextBox`).

### 4. Що відбудеться, якщо сервер недоступний або поверне помилку?
**Відповідь:** Якщо сервер недоступний, виникає виключення мережі (`HttpRequestException`) або помилка статусу (`HttpResponseMessage.EnsureSuccessStatusCode`). Завдяки блоку `try-catch` програма не «зависне» та не завершиться аварійно: вона перехопить виключення, змінить статусний рядок на повідомлення про помилку та виведе користувачу діалогове вікно (`MessageBox`) із деталями проблеми.
